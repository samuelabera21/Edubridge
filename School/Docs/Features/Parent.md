4.6 Parent / Guardian
The Parent/Guardian is a support and monitoring actor, not an administrator of the school.
Their responsibility in EduBridge is:
Monitor → communicate → support → respond → participate
The parent should be able to understand how their child is doing and communicate with the school, while official educational records remain controlled by authorized school personnel.
4.6.1 Parent Dashboard
The parent dashboard shall provide an overview of the child/children connected to the account.
The parent shall be able to view:
	Child's name
	School
	Grade
	Section
	Academic year
	Attendance summary
	Academic-performance summary
	Upcoming assessments
	Pending assignments
	Recent teacher feedback
	Support/intervention status
	School announcements
	Teacher messages
	Important notifications
	Upcoming school events
	Parent-teacher meetings
If a parent has multiple children, the dashboard shall allow switching between children.
Example:
My Children
Hana — Grade 10A
	Attendance: 91%
	Average: 78%
	Pending assignments: 2
	Attention: Mathematics
Abel — Grade 7B
Attendance: 95%
Average: 82%
No current concerns
4.6.2 Parent Profile
The parent shall be able to manage their own appropriate profile information.
The profile shall include:
	Full name
	Contact information
	Relationship to student
	Preferred communication method
	Notification preferences
	Connected children
	Account/security information
The parent shall not independently create an official parent-child relationship without school verification.
4.6.3 Child Connection
The parent shall be able to see children officially connected to their account.
The system shall show:
	Child name
	Student ID/reference where appropriate
	School
	Grade
	Section
	Relationship
	Connection status
Possible statuses:
	Pending verification
	Verified
	Rejected
	Suspended
The school shall remain responsible for validating the relationship where required.
4.6.4 Attendance Monitoring
The parent shall be able to view the child's attendance.
The parent shall see:
	Present
	Absent
	Late
	Excused absence
	Unexcused absence
	Attendance percentage
	Attendance history
	Attendance by subject/class where available
	Repeated absence alerts
Example:
Hana — August
	Present: 20
	Absent: 2
	Late: 1
	Attendance: 91%
The parent shall not directly edit attendance.
4.6.5 Attendance Alerts
EduBridge shall notify the parent when attendance requires attention.
Examples:
"Hana was marked absent today."
or:
"Hana has had 4 unexplained absences this month."
or:
"Hana's attendance has fallen below the school's monitoring threshold."
The exact thresholds should be configurable by the school rather than hard-coded nationally.
4.6.6 Academic Performance
The parent shall be able to view the child's academic performance.
The parent shall see:
	Subject
	Assessment
	Score
	Average
	Performance trend
	Teacher feedback
	Strengths
	Areas requiring improvement
Example:
Mathematics
Term 1: 61%
Term 2: 68%
Term 3: 78%
Trend: Improving
The parent shall not modify grades.
4.6.7 Assessment Results
The parent shall be able to view approved assessment results.
This may include:
	Quiz
	Test
	Assignment
	Project
	Continuous assessment
	Practical assessment
	Examination result
	Teacher feedback
Only results released by the authorized teacher/school should become visible.
4.6.8 Assignment Monitoring
The parent shall be able to see the child's assignment status.
The parent shall see:
	Assignment title
	Subject
	Teacher
	Assigned date
	Due date
	Submission status
	Score where released
	Teacher feedback
Example:
Mathematics Assignment
Due: Friday
Status: Submitted ✓
Score: 82%
The parent should not be able to submit or alter the child's work unless the school explicitly designs a specific parent-assisted process.
4.6.9 Learning Progress
The parent shall be able to see a summarized learning-progress view.
For example:
Mathematics
Current: 78%
Previous: 69%
Trend: ↑ Improving
English
Current: 84%
Previous: 82%
Trend: → Stable
This should help parents understand the child's development without exposing unnecessary internal teacher information.
4.6.10 Student Support / Intervention
The parent shall be informed when the school assigns appropriate support to the child.
The parent may see:
	Support reason
	Support type
	Teacher/support person
	Date
	Schedule
	Participation
	Progress
	Teacher feedback
Example:
Mathematics Support
Your child has been recommended for additional support in Geometry.
Session: Tuesday, 4:00 PM
This creates:
Teacher → School → EduBridge → Parent
rather than requiring manual communication every time.
4.6.11 Parent Response to Support
Where appropriate, the parent shall be able to:
	Acknowledge support recommendation
	Confirm participation
	Request clarification
	Contact teacher
	Request a meeting
	Provide relevant information to the school
The parent shall not independently approve an academic intervention that requires school authorization unless the school's policy specifically requires parental consent.
4.6.12 Teacher Communication
The parent shall be able to communicate with authorized teachers of their child.
The parent shall be able to:
	Send message
	Receive message
	Ask about academic progress
	Ask about attendance
	Ask for clarification
	Respond to teacher messages
	Request a meeting
Communication should be relationship-based.
A parent should not automatically be able to contact every teacher in the school.
4.6.13 Parent-Teacher Meetings
EduBridge shall support parent-teacher meeting coordination.
The parent may:
	View available meeting times
	Request a meeting
	Accept meeting invitation
	Reschedule where permitted
	Receive meeting reminder
	Join online meeting where supported
	View meeting status
Example:
Teacher: Hana's Mathematics Teacher
Meeting: Academic Progress
Date: Thursday
Time: 4:00 PM

4.6.14 School Announcements
The parent shall receive school announcements relevant to their child.
Examples:
	Academic-calendar changes
	Examination information
	School events
	Parent meetings
	School notices
	Important deadlines
	School activities
	Emergency announcements
The parent should be able to distinguish:
School announcement
from
Teacher message
from
Official authority announcement

Notifications shall include:
Attendance
	Child absent
	Repeated absence
	Attendance concern
Academic
	New result
	Performance concern
	Teacher feedback
Assignments
	Upcoming deadline
	Missing assignment
	Assignment result
Support
	Remedial support
	Tutorial
	Intervention update
School
	Announcement
	Meeting
	Event
Account
	Security
	Account changes
	Child connection changes
4.6.16 Parent Confirmation / Consent
Where school procedures require parent participation, EduBridge shall allow the parent to provide appropriate confirmation.
Examples:
	Activity participation
	School event participation
	Approved educational activity
	Parent-teacher meeting
	Selected school forms
	Emergency information confirmation
The system shall record:
	What was presented
	Parent response
	Date/time
	Status
	Relevant school record
The parent shall not use consent functionality to modify unrelated official academic records.

4.6.17 Parent Contact Information
The parent shall be able to review and request updates to:
	Phone number
	Email
	Address information where applicable
	Emergency contact information
	Preferred communication channel
Where the information is part of the official student/school record, changes should go through school verification.
4.6.18 Parent Feedback
The parent shall be able to provide feedback to the school.
Possible categories:
	Teaching/learning
	Student support
	Communication
	School facilities
	Learning resources
	School activities
	General suggestion
The school may use aggregated parent feedback as part of school improvement.
4.6.19 Parent Complaint / Concern
The parent shall be able to submit an appropriate concern.
Examples:
	Attendance record issue
	Academic record question
	Communication problem
	Learning-resource problem
	School facility problem
	Student welfare concern
	Safety concern
	Other school-related concern
The system shall route the concern to the appropriate school role.
4.6.20 Parent View of School Activities
Where the school uses EduBridge for activities, parents may see relevant information about:
	School events
	Student clubs
	Academic activities
	Competitions
	Parent activities
	Community participation
	Student achievements
The parent does not manage the activity unless assigned an appropriate governance role.
4.6.21 Parent Learning Support
EduBridge may provide parents with guidance about how they can support their child.
For example:
Your child is struggling with Geometry.
Recommended parent actions:
	Encourage regular practice
	Review the assigned learning resource
	Encourage attendance at remedial support
	Contact the Mathematics teacher if difficulties continue
This should be guidance, not a replacement for professional teaching.
4.6.22 AI Parent Assistant
AI can provide a controlled parent-facing assistant.
The AI may answer questions such as:
"How is my child doing this term?"
It can summarize authorized information:
	Attendance
	Performance trends
	Assignment completion
	Teacher feedback
	Support activities
Example:
"Hana's overall performance has improved compared with the previous assessment period. Mathematics improved, while Geometry remains an area for additional practice."
The AI shall only use information that the parent is authorized to see.
4.6.23 AI Parent Support Recommendations
The AI may recommend appropriate actions based on authorized information.
For example:
"Your child's attendance has decreased over the last three weeks. Consider discussing the reason with the class teacher."
or:
"Mathematics performance has declined in the last two assessments. The teacher has recommended additional practice."
The AI shall not diagnose the child, make disciplinary decisions, or make official academic judgments.
4.6.24 Parent Data Privacy
The parent shall only see information for the child/children officially connected to them.
The parent shall not see:
	Another student's data
	Another parent's information
	Private teacher notes
	Confidential school records
	Internal administrative records
	Regional statistics requiring restricted access
	Woreda statistics
	Federal education data
Even when the parent has access to their child's data, the system should apply minimum necessary visibility.
4.6.25 What the Parent SHALL NOT Control
The parent shall not:
	Change grades
	Change attendance
	Change examination results
	Change student enrollment status
	Assign teachers
	Change class placement
	Modify curriculum
	Create official assessments
	Approve student promotion
	Modify school statistics
	Modify teacher records
	Access other students' information
	Access restricted school administration information
The parent supports the education process.
The school administers the education process.
4.6.26 Parent Module — Final Feature Scope
For our implementation source of truth, the Parent/Guardian actor shall have:
1.	Parent Dashboard
2.	Parent Profile
3.	Child Connection
4.	Attendance Monitoring
5.	Attendance Alerts
6.	Academic Performance
7.	Assessment Results
8.	Assignment Monitoring
9.	Learning Progress
10.	Student Support / Intervention
11.	Support Response
12.	Teacher Communication
13.	Parent-Teacher Meetings
14.	School Announcements
15.	Notifications
16.	Consent / Confirmation
17.	Contact Information
18.	Parent Feedback
19.	Complaint / Concern
20.	School Activity Information
21.	Learning Support Guidance
22.	AI Parent Assistant
23.	AI Support Recommendations
24.	Parent Data Privacy
Core principle
The Parent module should answer:
"How can the parent understand and support the child's education?"
—not—
"How can the parent manage the school?"
That keeps the role consistent with the actor hierarchy we've established.
